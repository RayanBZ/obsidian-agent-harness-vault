# Mental Model Skill

## Purpose
Maintain persistent mental models that compound intelligence across sessions.

## Read Protocol (Start of Task)
1. Load your expertise YAML file
2. Review recent entries for relevant patterns
3. Check for warnings or anti-patterns from previous sessions

## Update Protocol (End of Task)
```yaml
- date: YYYY-MM-DD
  task: Brief description
  learnings:
    - What worked well
    - What didn't work
  decisions:
    - Key decision and rationale
  warnings:
    - Anti-patterns to avoid
```
