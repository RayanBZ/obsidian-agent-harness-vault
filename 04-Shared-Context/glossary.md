# Glossary

- **MOC** — Map of Content. Index note for a domain.
- **Atomization** — Breaking outputs into single-concept notes.
- **Mental Model** — YAML accumulating learnings across sessions.
- **Domain** — Path-scoped read/write permissions.
- **Blast Radius** — Zero, thanks to domain ownership.
- **Harness** — Runtime enforcing agent configs.
